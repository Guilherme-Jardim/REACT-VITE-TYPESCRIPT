# React Vite TypeScript

Mini rede social de posts feita para praticar React com TypeScript. Tem lista de posts, comentários, curtidas e uma barra lateral com o perfil.

## Tecnologias

- React 18 e TypeScript
- Vite
- CSS Modules
- date-fns
- phosphor-react (ícones)

## Como instalar e rodar

```bash
npm install
npm run dev
```

Outros comandos: `npm run build` gera a versão de produção e `npm run lint` roda o ESLint.
